# 굵은 글씨(Bold)

굵은 글씨는 별표 2개를 사용한다.
ex) 오늘은 즐거운 **금요일** 입니다.

---

# 이탤릭체(Italic)

이탤릭체 글꼴은 별표 1개를 사용한다.
ex) 내일은 황금같은 *토요일* 입니다.

---

# 굵은글씨 + 이탤릭체

이 경우에는 별표 3개를 사용한다.
ex) ***일요일***이 빨리 오면 좋겠다.

---

# 하이라이트(형광펜)

텍스트를 강조할때는 2개의 등호를 사용한다.
ex) 월요일에는 <mark>야구</mark> 경기가 없습니다.

---

# 취소선

삭제된 내용을 나타내기 위한 취소선은 물결표를 사용한다.
ex) 정가:~~10,000원~~, 할인가 : 5,000원

---

# 인용문

문단을 들여쓰기 하거나 중요한 문장을 인용할 때 사용.
시작 부분에 >를 붙인다.

> 첫번째 문장입니다.
> 두번째 문장입니다.
>
> > 세번째 문장입니다.
> > 네번째 문장입니다.
